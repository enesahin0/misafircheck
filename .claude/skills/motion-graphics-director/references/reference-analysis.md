# Reference Analysis Methodology

How to extract visual grammar from references without copying them. A reference is data to analyze, not a template to duplicate.

## The rule

**Analyze, don't imitate.** Extract the underlying *system* (why it works), then rebuild an original piece in the new subject's language using the extracted characteristics that serve the new brief. Copying surface elements (exact colors, exact text, exact layout) produces a knockoff; extracting grammar produces original work that feels as considered as the reference.

## Extraction checklist

When given an image, screenshot, video, or named style, extract these dimensions:

| Dimension | What to look for | Example extraction |
|---|---|---|
| Composition | Grid, alignment, negative space, focal placement | "Center-weighted with generous margins, single focal point" |
| Color relationships | Hues, saturation, contrast structure, accent usage | "Near-black bg, off-white ink, single hot accent used <5% of frame" |
| Typography | Weight contrast, tracking, case, hierarchy depth | "Ultra-heavy display + light mono metadata, wide-tracked caps" |
| Shape language | Angular vs organic vs geometric, stroke weight | "Angular — hexagonal marks, hard 90° cuts" |
| Motion language | How elements move — spring, slide, draw-on, glitch | "Elements arrive with overshoot and settle" |
| Pacing | Scene length, hold time, cuts per second | "Long holds, ~2.5s scenes, deliberate cuts" |
| Camera behavior | Static, drift, push, orbit, handheld | "Locked camera, subtle scale breathing" |
| Transitions | Hard cut, wipe, dissolve, morph | "Hard cuts, no dissolves" |
| Lighting | Flat, gradient, glow, rim light | "Dark field with one glowing focal element" |
| Depth | Flat, layered parallax, true 3D | "Layered 2.5D — background/subject/foreground planes" |
| Texture | Grain, noise, flat, gradient banding | "Heavy film grain over everything" |
| Editing rhythm | Where cuts land relative to beat/audio | "Cuts on downbeats" |
| Overall grammar | The one-sentence design philosophy | "Precision engineering: everything measured, nothing wasted" |

## Process

1. **Describe the reference in one sentence of grammar** — not what it shows, but its design philosophy. ("Swiss precision: mono type, hard grid, one red accent.")
2. **List which extracted characteristics serve the new brief.** A cyberpunk product reveal needs the glow + dark field; a corporate explainer needs the grid + hierarchy but not the glitch.
3. **Discard what conflicts** with the subject's tone. Luxury brand ≠ slam cuts. Playful ≠ long holds.
4. **Rebuild in the new subject's language**: same *class* of choices (heavy display type, scarce accent, grain), different *specifics* (different palette derived from the brand, different shape family matching the logo geometry).
5. **Sanity check**: put the new piece next to the reference. If a viewer sees sameness, you copied. If a viewer sees "these come from the same school of thought," you analyzed correctly.

## Special cases

- **Screenshot of a product/UI**: extract the design tokens (colors, radii, type scale, spacing) and animate the UI's own elements (cursor moves, panel slides, state changes) rather than decorating around it.
- **Video reference**: sample pacing and motion language at several timestamps — count cuts per second, note entrance styles, listen for beat alignment (if waveform available) or infer from cut rhythm.
- **Brand assets (logo, palette)**: derive shape language from the logo's geometry (round logo → circular orbits/blobs; angular logo → hexagons/diagonals). Derive palette: bg = near-black/near-white inversion of brand ink, accent = brand primary, used sparingly.
- **Named style only** ("cyberpunk", "Bauhaus", "vaporwave"): use the established grammar of that movement — its palette constraints, type conventions, texture, and motion vocabulary — but apply to the specific subject.
- **Multiple references**: extract grammar from each, choose a dominant one, blend secondary characteristics only where they don't fight (e.g., pacing from ref A, palette logic from ref B).
